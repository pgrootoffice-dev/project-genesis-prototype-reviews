# iPhone Preview

GitHub Pages is the only official Founder review route.

## Prototype Review

Device:
iPhone Safari

Review URL:
GitHub Pages workflowがDraft PR番号に対応する固定URLを発行・検証する。

Review Steps:
1. 先に「10秒 Motion Blocking」を無音で1回通して見る。
2. 次にBeatカードを読み、Frame 3（伝播）とFrame 4（接続・相互作用）の差を確認する。
3. Transition Contact Sheetと採用済みStatic Sequenceを比較する。
4. 最後にもう一度動画を見て、Frame 5が静かに世界規模へ開くか確認する。

Review Points:
- 0〜10秒で4 Beatが読めるか
- 主役の変化が明確か
- Frame間が単なるクロスフェードに見えないか
- Frame 3は異なる現象、Frame 4は接続と相互作用に見えるか
- Frame 5が希望を押し売りせず、世界規模の始動へ到達するか
- Motion Blockingとして局所修正できる骨格になっているか

Expected Feeling:
静かな世界の内部で一つの変化が生まれ、異なる現象へ伝わり、それらが結びついて世界全体が動き始める。完成映像の華美さではなく、意味とテンポの骨格が一度で読める。
