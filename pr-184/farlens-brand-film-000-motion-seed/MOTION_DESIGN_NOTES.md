# Motion Design Notes

Status: WORKING TEST NOTES — NON-CANONICAL

## 共通設計

- 720×1280 / 9:16 / 30fps / H.264 / yuv420p / 無音。
- 元JPEGを各フレームの全画面ベースとして保持し、生成・再解釈・物体追加はしない。
- 光は「意味のある既存要素」だけに重ねる。Glowは局所・低Alpha。
- 動作後に止まる時間を必ず残す。Loop前提にしない。
- iPhone版は540×960 / H.264 / faststart。内容とTimingはMasterと同じ。

## Section 0｜Brand Entrance

Duration: 5.4秒。役割: 接続の誕生。

- 0.00–0.55: 静止。
- 0.55–1.25: 世界側の既存光点に弱い立ち上がり。
- 1.05–3.55: 元画像内のオレンジ線を消したり再生成せず、その既存軌道上だけに細い追光を伸ばす。
- 3.15–4.15: 家の既存窓へ弱い暖色を足す。
- 0.60–4.20: 中心固定で最大1.2%ズーム。
- 4.20–5.40: 停止してSection 1への受けを作る。

判断: 入口として意味は明確。元線が開始時から見えるため「線そのものの生成」ではなく「つながりが認識される追光」として実装した。これは元画像保持を優先した意図的な差分。

## Section 4｜Research

Duration: 5.6秒。役割: 分散情報の順次確認と整理。

- 0.55秒から5本の既存Flow上を0.35秒ずつ時差で弱い光が移動。
- 各Flowの途中で小さな確認点を一度だけ弱く点灯。
- 3.55–4.72に中央核を一度だけ少し明るくし、強いPulseは使わない。
- 0.6%の奥行き差と約1.5pxの横移動。吸い込み・全線同時移動はしない。
- 最後約0.9秒は整理後の停止。

判断: 「集める」は中心方向のTravel、「確かめる」はStaggered check point、「読み解く」は一度だけの中央整理光に分離した。

## Final｜Brand Lock

Duration: 5.4秒。役割: 説明の終了とブランドの残留。

- 0.30–1.70: 既存光点へ14pxの弱い残響が寄り、停止。
- 0.95–2.75: FARLENS文字を再描画せず、文字帯の一時的な減光を解除して元画像の文字を露出復帰。
- Zoom、Glow文字、フレア、フェードアウトなし。
- 3.20–5.40: 元画像の見え方で完全停止。

判断: ロック済み文字の位置・字間・形・最終明度を一切再構成しないことを、派手な登場より優先した。

## Motion Grammar candidates

Working candidates only; no Canonical promotion.

1. **Meaning-first micro-motion** — 1画面1機能。光は意味のある既存Anchorだけを動かす。
2. **Stagger, never swarm** — 複数情報は時差で動かし、同時総動員を避ける。
3. **Resolve once** — 核の明度変化は整理された一瞬だけ。一度で着地する。
4. **Move → settle → hold** — 動きの後に停止を置き、次Sectionや余韻へ渡す。
5. **Locked asset first** — 既存形状を再生成せず、必要なら追光・露出復帰・1%前後の画面Motionに限定する。

## CEO判断が必要なこと

- Section 0の「元線を残した追光」が、最初の5秒として十分に惹きになるか。
- Section 4の静かな時差が、中盤の見せ場として弱すぎないか／ちょうどよいか。
- Finalの文字露出復帰が「広告の締め」ではなく「ブランドが残る終わり」に感じられるか。
